{%- comment -%} Dark/light theme toggle. Inlined into by _includes/head.html rather than linked, because setting data-theme has to happen before first paint -- a linked script would let the wrong theme flash on every load. Both palettes live in assets/css/main.scss as custom properties under :root and [data-theme="light"], so switching is one attribute flip: no stylesheet swap, no network request. (The previous design needed a build-time plugin to achieve this, because minimal-mistakes baked its colours into compiled Sass -- see docs/superpowers/specs/2026-08-27-theme-css-merge-design.md.) The button itself is server-rendered in _includes/masthead.html; this only sets its glyph and binds the click. {%- endcomment -%}
