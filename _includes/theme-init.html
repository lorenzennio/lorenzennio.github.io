{%- comment -%} Dark/light theme. Inlined into by _includes/head.html rather than linked, because setting data-theme has to happen before first paint -- a linked script would let the wrong theme flash on every load. Both palettes live in assets/css/main.scss as custom properties under :root and :root[data-theme="light"], so switching is one attribute flip: no stylesheet swap, no network request. (The previous design needed a build-time plugin for this, because minimal-mistakes baked its colours into compiled Sass -- see docs/superpowers/specs/2026-08-27-theme-css-merge-design.md.) The control itself is server-rendered in _includes/masthead.html as a single sun/moon button; this keeps its icon and label in sync and binds the click that flips the theme. It also keeps in sync with --bg: mobile Safari otherwise infers the UI-chrome tint from the page background itself, and can land on a blend of the SSR default and the flipped-to theme (see the comment on that meta tag in head.html). {%- endcomment -%}
