{%- comment -%} Dark/light theme. Inlined into by _includes/head.html rather than linked, because setting data-theme has to happen before first paint -- a linked script would let the wrong theme flash on every load. Both palettes live in assets/css/main.scss as custom properties under :root and :root[data-theme="light"], so switching is one attribute flip: no stylesheet swap, no network request. (The previous design needed a build-time plugin for this, because minimal-mistakes baked its colours into compiled Sass -- see docs/superpowers/specs/2026-08-27-theme-css-merge-design.md.) The control itself is server-rendered in _includes/masthead.html as two labelled options; this only keeps their checkboxes in sync and binds clicks. {%- endcomment -%}
